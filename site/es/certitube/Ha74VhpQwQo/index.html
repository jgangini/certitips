AI Data Platform for God's Eye View

AI Data Platform for God's Eye ViewCERTITUBE

Resumen

¿Cómo reunir publicaciones de redes sociales y datos de sensores para entender qué ocurre en una zona?

En esta demo te muestro cómo ampliar God's Eye View con Oracle AI Data Platform para analizar eventos sobre un mapa y consultar sus evidencias con un asistente de IA.

Inicio

Inicio del video. La presentación hablada de la demostración comienza en el segundo 14.

Presentación de la demo y mapa por capas

La demo amplía el proyecto open source God’s Eye View con Oracle AI Data Platform. El mapa reúne distintas capas para interpretar el entorno y apoyar decisiones.

Redes sociales: correlación y severidad

Una matriz de correlación relaciona publicaciones similares de diferentes usuarios. La clasificación de severidad aumenta conforme se acumulan reportes relacionados; el ejemplo emplea publicaciones de redes sociales.

Sensores para contrastar los reportes

Las mediciones de nivel del río, precipitaciones, temperatura, humedad del suelo y velocidad del viento permiten contrastar lo reportado en redes sociales.

Object Storage y procesamiento en streaming

La información llega a Object Storage y se procesa en streaming con Oracle AI Data Platform antes de consultarse desde la aplicación.

OCI Generative AI e interacción por voz

La explicación presenta servicios de OCI Generative AI e interacción de voz, con conversión de voz a texto, texto a voz y modelos generativos de texto.

Demo: navegación a Colombia y activación de capas

El recorrido navega a Colombia mediante una instrucción de voz y habilita las capas personalizadas de sensores y redes sociales.

Análisis geográfico de publicaciones e incidencias

El mapa permite explorar una zona y revisar las publicaciones, incidencias y niveles de severidad reportados por diferentes usuarios.

Sensores en alerta e incendio con datos sintéticos

La demostración compara sensores normales y sensores en alerta. El escenario de incendio utiliza datos sintéticos: las señales rojas y las publicaciones relacionadas pertenecen al ejemplo.

Consultas con Agent Flow

Una capa de consulta con Agent Flow recibe una pregunta sobre los eventos y consulta las tablas correlacionadas en Oracle AI Data Platform.

Respuesta del asistente y evidencias del evento

El asistente devuelve información del evento y sus evidencias. En el caso sintético de incendio se mencionan 28 publicaciones relacionadas de diferentes fuentes.

  9. 9Oracle AI Data Platform Workbench: X Sentiment Analysis With OCI Language & Agent Factory2026-01-19Convierte los comentarios de X en datos que puedas analizar con SQL y consultar desde un agente. La demostración integra Oracle AI Data Platform Workbench, OCI Language, Oracle Autonomous AI Database y Agent Factory. Se crean el servicio, el workspace y el clúster, se instalan las librerías y se preparan las conexiones. Un notebook de Python extrae respuestas a una publicación de X y obtiene sus puntuaciones de sentimiento con OCI Language. El notebook se organiza en un job con registros de ejecución y una programación automática. Al final, Agent Factory se conecta a la base de datos para responder preguntas en lenguaje natural sobre los comentarios. Las respuestas se contrastan con consultas SQL para seguir el recorrido desde la extracción hasta la consulta conversacional.
