# Oracle Cloud Infrastructure icon provenance

These seven SVG assets come from the local OCI Architecture Diagram plugin, version 0.4.10, assets/oci-icons/catalog.json. The plugin catalog identifies their source as Oracle OCI local SVG artwork. Oracle product names and their artwork remain attributable to Oracle.

The reviewed plugin bundle did not supply a separate license or redistribution notice for this artwork. This file records provenance; it does not assign an open-source license or assert additional permission.

Six SVG files are exact copies, including object-storage.svg. data-lakehouse.svg removes only Inkscape/Sodipodi editor metadata whose undeclared XML prefixes prevented standalone SVG loading; geometry, colors and viewBox are preserved. Original and delivered hashes are recorded in icons-manifest.json. Dark-mode white outlines use presentation CSS only; the original SVG bytes remain unchanged.

The Data Lakehouse and Analytics pictograms are catalog symbols, not newly invented product logos. Product identity comes from the accompanying Oracle Autonomous AI Lakehouse and Oracle Analytics Cloud labels. The AI Data Platform asset is the catalog's Workbench pictogram.
