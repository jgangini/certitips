RECURSOS DE ESTUDO

Ele fala a língua dos oficiais.

Termos técnicos em espanhol e com suas diferenças importantes.

Use os termos em inglês para reconhecê-los em documentação oficial e materiais. As definições são operacionais: eles procuram ajudá-lo a escolher e explicar, e não memorizar palavras.

Agentes e raciocínio

Termo O que isso significa? Não o confunda com
Agente. Um sistema que decide ações para um alvo usando um modelo, ferramentas e um ciclo. Qualquer chatbot ou oleoduto normal.
LLM Um modelo de linguagem que produz uma saída de um contexto. Um artista com acesso automático ao seu sistema.
Inferência Desempenho do modelo para produzir uma saída. Modelo de treinamento.
Ferramenta. Capacidade incutível com contrato de entrada/saída. Uma instrução escrita que concede permissões.
Ferramenta chamando. Saída estruturada que requer usar uma ferramenta. O execução efetivo dessa ferramenta.
Agente Loop. Um ciclo que coordena decisões, ferramentas, observações e parar. Um único modelo chamada.
Reagir Um padrão que modifica o raciocínio e as ações e incorpora observações. uma obrigação de mostrar raciocínio interno para o usuário.
Corrente. Um problema é a decomposição em um passo de raciocínio. Uma ferramenta para visualizar dados externos.
Estado Informação que o sistema mantém durante o fluxo. Mude os pesos do modelo.
Janela de contexto Quantidade de contexto que um chamada para modelar pode processar. Memória permanente ilimitada.

Orquestra e integração

Termo O que isso significa? Distinção útil
LangChain Framework com interfaces e componentes para aplicações de modelos. A aplicação mantém a responsabilidade por permissões e validação.
LCEL Como compor componentes em correntes LangChain. O operador de composição não faz uma corda autônoma.
MCP host Aplicação que contém e coordena clientes MCP. Não precisa ser o modelo.
Cliente MCP Componente que mantém uma conexão com um servidor MCP. Anfitrião e cliente têm responsabilidades diferentes.
Servidor MCP Expõe habilidades aos clientes conforme o protocolo. Não substitui o ciclo do agente por si só.
Recurso Conteúdo ou dados expressos por um servidor MCP. É uma ferramenta executável.
Propt. Placa de interação oferecida por um servidor MCP. Acesso a todas as instruções do sistema.
Responses API API OpenAI que integra respostas, ferramentas e opções de contexto / estado. Não execute nenhuma função Python local automaticamente.
Agents SDK A biblioteca de orquestração de agentes, ferramentas, transferências e outras capacidades. Um serviço de aluguel de sua inscrição.
Passagem. Transferência de monitoramento de conversação para um agente especialista. Use outro agente como ferramenta e volte para o agente principal.

Segurança e operação.

Termo O que isso significa? Pergunta a fazer
Guarrail. Controle que valida ou restringe parte do fluxo. Em que ponto e sobre que conteúdo são executados?
Injecção de propto. Instruções maliciosas incluídas em inputs ou conteúdo não confiáveis. Estou processando dados externos como instruções autorizadas?
Último privilégio. Conceda apenas o permissões necessário. Essa ferramenta pode fazer mais do que a tarefa requer?
Humano-no-loop Intervenção humana em decisões concretas. Qual operação sensível exige confirmação?
Rastreando. Registro de eventos operacionais do fluxo. Posso reconstruir chamadas, erros e tempos?
Hora da corrida O ambiente que implementa e coordena a conduta do agente. Quem mantém sessões, executa ferramentas e aplica limites?
Avaliação Uma verificação sistemática com casos e critérios estabelecidos. Estou medindo precisão, segurança e custo, bem como fluidez?

Dados e Recuperação

Termo O que isso significa? Distinção útil
Embutindo. Representação numérica de conteúdo. Não é nem o documento original nem uma garantia de veracidade.
Chunk. Fragmento de um documento usado na recuperação. Um corte arbitrário pode perder o contexto necessário.
Vetor de busca. Search por similaridade entre performances vetoriais. Similitude não significa precisão factual.
RAG Retomar o contexto e usá-lo para basear uma geração. Não significa treinar ou ajustar o modelo.
Select AI Capacidades de usar linguagem natural com modelos IA services e dados Oracle. A geração de SQL não dá nova permissões.
Select AI Agent Um framework para definir agentes, tarefas e ferramentas perto de dados. Isso não significa que os pesos LLM são executados dentro da base.
Soldado Agent Factory Ambiente para construir agentes e fluxos com interface visual. A configuração visual não remove a necessidade de governança.

Um teste de compreensão

Isso explica a diferença entre Ferramenta chamando., MCP y Corra. com uma ordem de uma tenda. Uma resposta sólida identifica solicitação estruturado, um protocolo de integração e um ambiente que implementa e coordena o trabalho. Se você usar todos os três termos como sinônimos, volte para Módulo MCP.
