FUNÇÃO INDIVIDUAL

Ele fala a língua dos oficiais.

Técnico termos em espanhol e com suas diferenças importantes.

Use os termos em inglês para reconhecê-los em documentação oficial e materiais. As definições são operacionais: eles procuram ajudá-lo a escolher e explicar, e não memorizar palavras.

Agentes e raciocínio

Termo O que isso significa? Não o confunda com
Agente. Sistema A que decide ações para um objetivo, usando um modelo, ferramentas e um ciclo. Qualquer chatbot ou oleoduto normal.
LLM A modelo de linguagem que produz uma saída de um contexto. A function performer com acesso automático ao seu sistema.
Inferência Desempenho do modelo para produzir uma saída. Modelo de treinamento.
Ferramenta. Capacidade incutível com contrato de entrada/saída. A escreveu instruções que ele mesmo concede permissões.
Ferramenta chamando. Saída estruturada que requer usar uma ferramenta. O execução efetivo dessa ferramenta.
Agente Loop. Ciclo A que coordena decisões, ferramentas, observações e parar. A único modelo chamada.
Reagir A padrão que modifica raciocínio e ações e incorpora observações. uma obrigação de mostrar raciocínio interno para o usuário.
Corrente. A decomposição do problema A em um passo de raciocínio. Ferramenta A para visualização de dados externos.
Estado Informação que o sistema mantém durante o fluxo. Mude os pesos do modelo.
Janela Contexto Quantidade de contexto que um chamada para o modelo pode processar. Memória permanente ilimitada.

Orquestra e integração

Termo O que isso significa? Distinção útil
LangChain Framework com interfaces e componentes para aplicações de modelos. A aplicação mantém a responsabilidade por permissões e validação.
LCEL Como compor componentes em correntes LangChain. O operador de composição não faz uma corda autônoma.
MCP host Aplicação que contém e coordena clientes MCP. Não precisa ser o modelo.
Cliente MCP Componente que mantém uma conexão com um servidor MCP. Host e cliente têm responsabilidades diferentes.
Servidor MCP Expõe habilidades aos clientes conforme o protocolo. Não substitui o ciclo do agente sozinho.
Recurso Conteúdo ou dados expressos por um servidor MCP. É uma ferramenta executável.
Propt. Placa de interação oferecida por um servidor MCP. Acesso a todas as instruções do sistema.
Responses API API OpenAI que integra respostas, ferramentas e opções de contexto / estado. Não execute uma função Python local automática.
Agents SDK A biblioteca de orquestração de agentes, ferramentas, transferências e outras capacidades. A serviço de aluguel de sua aplicação.
Passagem. Transferência de monitoramento de conversação para um agente especialista. Use outro agente como ferramenta e volte para o agente principal.

Segurança e operação.

Termo O que isso significa? Pergunta que deve ser feito
Guarrail. Controle que valida ou restringe parte do fluxo. Em que ponto e sobre que conteúdo são executados?
Injecção de propto. Instruções maliciosas incluídas em inputs ou conteúdo não confiável. Estou processando dados externos como instruções autorizadas?
Último privilégio. Conceda apenas permissões necessário. Essa ferramenta pode fazer mais do que a tarefa requer?
Humano-no-loop Intervenção humana em decisões concretas. Qual operação sensível exige confirmação?
Rastreando. Registro de eventos operacionais do fluxo. Posso reconstruir chamadas, erros e tempos?
Hora da corrida O ambiente que corre e coordena a conduta do agente. Quem mantém sessões, executa ferramentas e aplica limites?
Avaliação Verificação sistemática A com casos e critérios estabelecidos. Estou medindo exatidão, segurança e custo, bem como fluidez?

Dados e Recuperação

Termo O que isso significa? Distinção útil
Embutindo. Representação numérica de conteúdo. Não é um documento original ou uma garantia de veracidade.
Chunk. Fragmento de um documento usado na recuperação. Um corte arbitrário pode perder o contexto necessário.
Vetor de busca. Search por semelhança entre performances vetoriais. Similitude não significa fato exatidão.
RAG Retomando o contexto e usando-o para basear uma geração. Não significa treinar ou ajustar o modelo.
Select AI Capacidades para usar linguagem natural com IA services / modelos e dados Oracle. A geração de SQL não dá nova permissões.
Select AI Agent Framework A para definir agentes, tarefas e ferramentas próximas de dados. Isso não significa que os pesos LLM são executados dentro da base.
Soldado Agent Factory Ambiente para construir agentes e fluxos com interface visual. A configuração visual não remove a necessidade de governança.

Teste A de compreensão

Isso explica a diferença entre Ferramenta chamando., MCP y Corra. com uma ordem de uma tenda. A resposta sólida identifica solicitação estruturado, um protocolo de integração e um ambiente que implementa e coordena o trabalho. Se você usar todos os três termos como sinônimos, volte para Módulo MCP.
