Agentes próximos aos seus dados.

relação, Select AI Agent, Agent Factory e servidor MCP da Autonomia.

Os agentes exigem informações confiáveis e operações controladas. Oracle AI Database contribui com recursos de dados: busca vetorial, construção de agentes, orquestração com Select AI Agent e integração com MCP. Cada um resolve uma parte diferente do problema.

Conceitos-chave

AI Vector Search encontra elementos semanticamente próximos. Soldado Agent Factory oferece construção visual de agentes e fluxos de trabalho. Select AI Agent Permite configurar agentes, tarefas, ferramentas e equipamentos usando recursos de banco de dados. O MCP Server de Autonomous AI Database Expandir ferramentas para clientes suportados. Um não substitui automaticamente o outro.

Objetivos do módulo

  • Explicar incorporação, procurar similaridade e sua diferença contra RAG.
  • Preparação da trilha, armazenamento, indexação e consulta vetorial.
  • Escolha entre pesquisa, construção visual, equipamentos de agente e exposição MCP.
  • Mantenha dados permissões mesmo que a consulta chegue em uma linguagem natural.

Vetor e semelhança.

A Incorporando representa dados usando uma lista de números gerados por um modelo. Sua utilidade depende de como as relações relevantes são refletidas nesse espaço. Duas frases podem ser as mesmas sem compartilhar palavras exatas, e uma busca semântica pode recuperar o relação.

Para texto, o caminho é texto → tokenizer → modelo → vetor. tokens pode ser palavras ou partes de palavras: palavras contam não significa tokens contar. Se o limite de entrada do modelo for ultrapassado, o conteúdo pode ser truncado. É por isso que dividimos documentos longos antes de gerar incorporações. Só tamanho e... Sobreposição entre fragmentos para preservar o contexto e verificar a recuperação com perguntas representativas sem aplicar um número universal. Oracle explique isso. Mudanças e... Parâmetros de fragmentação.

O modelo de incorporação de documentos e consultas deve produzir representações apoiadas: mudar dimensões ou modelo sem regenerar e validar a comparação de quebras de dados. A métrica de distância também importa. Cosseno. foca-se em orientação. Euclidiano mede a separação geométrica. Escolha a métrica recomendada para o modelo e verifique sua conduta com exemplos de seu domínio.

A coluna. VECTOR permite armazenar incorporações com identificadores, texto, preços ou permissões. A busca vetorial pode ser combinada com filtros relacionais. "Semanticamente semelhante" significa "verdadeiro" ou "autorizado"; Aplique restrições de acesso antes de fornecer o documento modelo.

Vetor Search Fluxo de trabalho

  1. Prepare e divida conteúdo em fragmentos compreensíveis, preservando origem e metadados.
  2. Gera incorporações com um modelo compatível, dentro da base com ONNX como apropriado ou por um serviço externo.
  3. Salve os vetores com os dados de negócios e seus identificadores.
  4. Avaliar se um índice vetorial deve ser criado: HNSW usando uma estrutura de e-graph IVF agrupando vetores em divisórias. Um índice acelera alguns cenários com compromissos recursos e recuperação.
  5. Gera a incorporação da consulta, procura similaridade e aplica filtros SQL. Se você construir RAG, dê os fragmentos relevantes para LLM para formular uma resposta com fontes.

Esse curso depende do Fluxo de trabalho oficial de AI Vector Search. A indexação é opcional por escala e alvo. Uma busca exata pode ser útil como referência. RAG adiciona geração sobre conteúdo recuperado: este não é outro nome para salvar vetores.

Em uma implementação, DBMS_VECTOR_CHAIN Permite a Corrente UTL_TO_TEXT para extrair texto, UTL_TO_CHUNKS Para dividir e UTL_TO_EMBEDDINGS Para produzir vetores, a saída de cada estágio alimenta o seguinte. Você tem que configurar o modelo e verificar os requisitos do Oracle Text e do fornecedor escolhido. e... Guia utilitários Detalha essas condições.

Exemplo passo a passo

Uma tenda tem descrições de mochilas e o usuário quer "uma mochila leve para usar laptop, por menos de solas 200."

Primeiro, ele mantém descrição, preço, categoria e incorporação de cada produto. Converta a demanda em um vetor compatível com os existentes. Recupera semanticamente candidatos próximos e filtra preço e disponibilidade com dados estruturados. Ele pede e verifica que a descrição realmente menciona espaço para o laptop. Finalmente, ele apresenta opções e seus atributos apoiados pela tabela.

Que ensinar SQL significa uma mesa productosSua coluna. embedding de um tipo VECTOR e o vetor de referência ligado como :query_embedding. Use. COSINE Só se o modelo corresponder a eles. FETCH EXACT torna explícita uma busca exata para os três vizinhos mais próximos que cumprem os filtros. Consulta Exatamente a sintaxe oficial de busca..

SELECT nombre, precio, descripcion
FROM productos
WHERE precio < 200 AND stock > 0
ORDER BY VECTOR_DISTANCE(embedding, :query_embedding, COSINE)
FETCH EXACT FIRST 3 ROWS ONLY;

Também tente uma consulta incomparável e um produto semanticamente próximo, mas supera o preço. A resposta certa pode ser: "Eu não encontrei uma opção que preenchesse as duas condições." A semelhança não permite que eles ignorem restrições e inventem ações.

Uma solução completa: resposta com evidência.

Os dois ramos resolvem necessidades diferentes. O busca semântica. Reformas fragmentos relevantes para fundamentar uma resposta. a Consulta SQL Obtém resultados estruturados, por exemplo, o estado e uma quantidade de ordem. Ambos requerem monitorar as informações que podem ser encontradas com a identidade que uma operação opera. Mudar dados ou executar uma ação de negócios também requer uma ferramenta autorizada e sua validação.

Como ler imagem: para "que política ela se aplica?" selecione recuperação documental; "Quanto esse cliente pagou?" indica consulta estruturada. Os conectores representam relações de referência e resposta, e não representam uma sequência rígida. O modelo não-recebe sem restrições de acesso direto à base, nem esta visão significa que LLM funciona dentro de Oracle AI Database.

Select AI Agent

Select AI Agent articula Ferramentas., tarefas, Agentes. y Equipes.. Uma ferramenta oferece uma operação Uma tarefa define o trabalho. Um agente faz isso com suas capacidades; Uma equipe coordena as entradas. Pode haver uma ordem sequencial ou um supervisor que seleciona tarefas. As visões da história ajudam a observar execuções, de acordo com Conceitos oficiais.

O pacote. DBMS_CLOUD_AI_AGENT Gerencie essas capacidades e perfis IA configurem o acesso do modelo. Que o agente está integrado com a base não significa que os pesos do LLM estão alojados dentro do motor. Não confunda esse caso com uma incorporação do modelo ONNX admitida na base.

MCP em Autonomous AI Database

O servidor gerenciado permite que você descubra e invoque ferramentas Select AI Agent de aplicativos MCP suportados. Os controles de identidade e banco de dados ainda são importantes: credenciais, papéis, políticas de linha, rede e auditoria delimitam o acesso. Um perfil com contexto de quadros ajuda a gerar consultas, mas não garante SQL direito ou substituir permissões. O Arquitetura oficial do servidor descreve estas camadas.

Distinguir três implementações de ferramentas: uma ferramenta SQL usa um perfil NL2SQL para traduzir perguntas. Uma ferramenta. RAG Recupera o conhecimento por meio de uma busca vetorial; Uma ferramenta personalizada chamadas a PL / SQL funçãoPor exemplo, para consultar o inventário. Eles estão registrados com DBMS_CLOUD_AI_AGENT.CREATE_TOOLe a sua Tipos e requisitos. Gerar SQL não autoriza seu execução: o aplicativo e a ferramenta têm que limitar as ações que foram autorizadas e a base aplicando os privilégios da identidade performática. Verifique quais ferramentas estão registradas. MCP.

Erros comuns.

  • Considere incorporar uma cópia legível do documento.
  • Suponhamos que um índice aproximado sempre recupere exatamente os mesmos vizinhos que uma busca exata.
  • Para fundir geração de SQL com permissão para funcionar.
  • Dizer que usar um modelo local remove toda a latência.

Exercício de seleção.

Você quer dois aplicativos externos para consultar um recurso de inventário autorizado sem hospedar outro servidor MCP. Qual é a capacidade dele e o que você não deveria desistir?

Solução

O MCP Server gerenciado Autonomous AI Database pode exibir ferramentas de framework Select AI Agent como versão e configuração suportadas. Ainda assim você tem que definir a ferramenta, permissões, identidade do cliente e conectividade. O protocolo não garante que todo usuário possa consultar qualquer inventário e não transformar um recurso de leitura em uma autorização de escrita.

Fontes e revisão

Voltar para AI Vector Search, Agent Factory, Select AI Agent y Autonomia MCP Server. Para fechar o módulo, atribua uma capacidade para todas as necessidades: pesquisar, montar, orquestrar ou exibir ferramentas.
