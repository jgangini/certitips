# CertiTips

A multilingual knowledge hub that brings information from different topics and collections together. Explore visual guides, connect ideas, practice, and learn with others through quizzes, videos, and AI assistance.

Current collections cover Oracle Cloud, AI, and data management, including certification preparation and practical use cases. CertiTips is designed to organize knowledge beyond a single subject or certification.

**[Visit CertiTips](https://jgangini.github.io/certitips/)** | **[Start in English](https://jgangini.github.io/certitips/en/)**

## Choose your language

The website is available in [English](https://jgangini.github.io/certitips/en/), [Español](https://jgangini.github.io/certitips/es/), [Português (Brasil)](https://jgangini.github.io/certitips/pt/), and [Italiano](https://jgangini.github.io/certitips/it/). Use the language selector to switch while keeping your current page.

## Get started

1. **Choose a language and a topic.** Browse the content groups and open an available guide. Courses marked “Coming soon” are still being prepared.
2. **Read, explore, and practice.** Use the lessons and visual explanations, answer practice questions, and review the reasoning behind each answer.
3. **Go further.** Ask CertiChat about the material, watch a related CertiTube video, or host a CertiQuiz session with your team. Use CertiSearch when working through an OCI architecture case.

Open the website directly in your browser; no local installation is needed. Live quizzes and AI-assisted features use connected services. The language selector changes the website's content and interface; videos retain their original audio.

## About this repository

This repository contains the currently published website in [`site/`](site/) and the GitHub Pages publishing workflow. Pages verifies the release inventory and publishes those files without rebuilding them. [`release.json`](release.json) identifies the published release and its file hashes.

Application source, backend services, development tools, and tests are maintained in a separate private repository. This public repository does not contain development builds, experiments, or quarantined releases.
